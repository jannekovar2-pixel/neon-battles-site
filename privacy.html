Privacy Policy

Neon Battles Uploader · effective 26 October 2026

Who we are

Neon Battles is a hobby project that makes daily battle-simulation videos. Neon Battles Uploader is its tool for publishing those videos on the project's own YouTube channel. Contact: jannekovar2@seznam.cz.

What the app does

Neon Battles Uploader uploads videos made by the Neon Battles project to the Neon Battles YouTube channel, which the project owns. It uses the YouTube API Services with a single permission, youtube.upload (upload videos). It is used only by the channel's owner; it is not offered to other people and nobody else signs in to it.

What data it uses

  • It does not collect, store, share or sell any data about other users or viewers.
  • It does not read the channel's or anyone's private data; it only sends our own video files with their title and description to YouTube.
  • It uses no cookies, no analytics and no advertising.

Where the access token is kept

The sign-in creates an OAuth access (refresh) token for the Neon Battles channel. It is stored encrypted in GitHub Secrets of the project's private repository and is used only by the automated daily upload. It is never published or shared with anyone.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google's security settings). After that, the stored token no longer works; it is then also deleted from GitHub Secrets.

YouTube and Google

Neon Battles Uploader uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

This website

This website is hosted on GitHub Pages and sets no cookies. GitHub may log technical data such as IP addresses for security; see the GitHub Privacy Statement.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
